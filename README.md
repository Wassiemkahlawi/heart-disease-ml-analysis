# Heart Disease Analysis

## About this project

This project documents my journey into data science.
The goal is not only to build a machine learning model, but to understand the data through exploratory analysis and learn the reasoning behind each step.

Analysis of a heart disease dataset with a focus on:
- Exploratory data analysis
- Data cleaning
- Classification models
- Interpretability of ML models
